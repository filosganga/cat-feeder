# The electronics live in their own printed case

The original plan reused each feeder's LCD window and button hole. With feeders
of different brands that means one mounting design per model, fitted to
interiors that differ. Instead the board, driver, RTC and any panel and knob go
in a separate 3D-printed enclosure, and each feeder gets one hole for the motor
and switch cable.

- One design fits every feeder, because it is fitted to none.
- The display is no longer bound by a 40 × 18 mm window, so the production
  panel is a 0.96" 128×64 — but still **21 columns**.
- A wrong hole is a reprint, so the interface can keep changing after the
  feeders are closed up.
- The case can sit out of a cat's reach, which is the knob's defence
  (ADR-0010).
